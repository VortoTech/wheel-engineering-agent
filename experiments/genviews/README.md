# 生图三视图测试

问题：能不能让生图模型把一张斜拍照片「画成」正交正视图 / 截面图，再拿去建模？

- `generate.py`：把照片和提示词发给千问 / 万相生图模型，默认走中转站 `/v1/images/edits`（`.env` 里的 `RELAY_BASE_URL` + `RELAY_API_KEY`），`--via dashscope` 直连百炼（`DASHSCOPE_API_KEY`）。密钥不打印；照片会上传到阿里云。
- `compare.py`：把生成的正视图（深色 = 实体）和照片的材料遮罩放到同一套极坐标（外圈半径的 0.30–0.76）里比较：
  - 主谐波：组数、辐条数是否一致；
  - 自动对齐旋转和镜像；
  - 在 0.85–1.15 之间搜索径向比例，因为生成图常改轮唇和轮辋的比例；
  - 按面积加权算 IoU。
- `test_compare.py`：合成测试。旋转、镜像后的同一图案应能对齐回来；组数画错应能识别出来。

```bash
P="/Users/happyding/Desktop/轮毂/Weixin Image_20260728215534_27232_4.jpg"
.venv/bin/python experiments/genviews/generate.py "$P" --model wan2.7-image --out artifacts/genviews/wan2.7-image
.venv/bin/python experiments/genviews/compare.py artifacts/genviews/wan2.7-image/front_silhouette.png \
    --ref-mask artifacts/window-spike/sam_arms.png --ref-context artifacts/window-spike/context.json
```

## 结果（2026-09-13，照片 #18，8 组双辐）

| 模型 | 视图 | 耗时 | 主谐波（参考 16/8/24） | IoU（检测半径 / 最佳比例） | 看图 |
| --- | --- | --- | --- | --- | --- |
| wan2.7-image | 剪影 | 9 s | 16/8/24 ✓ | 0.64 / 0.64（×1.00） | 真剪影；辐条末端画成细双线，窗口内角更圆 |
| qwen-image-3.0 | 剪影 | 61 s | 16/8/24 ✓ | 0.38 / 0.40（×0.92） | 没画成剪影，画成哑光黑轮毂，轮辋内壁的暗部被算成实体 |
| qwen-image-3.0 | 渲染 | ~60 s | 17/8/15 | 0.29（无效） | 去透视效果很像原图：五孔、中心盖、铆钉都在；但写实图无法用阈值分割 |
| wan2.7-image | 渲染 | 9 s | 16/8/17 | 0.36（无效） | 同上 |
| wan2.7-image | 截面 | 10 s | — | — | **失败**：画成带剖面线的正视线稿，不是截面 |
| qwen-image-3.0 | 截面 | 147 s | — | — | **失败且有误导**：图面像正式工程图（标题栏、剖面线、参数表），但几何是编的，见下 |

qwen 截面的问题：
- 剖面里画出了圆形螺栓孔，剖切面上不可能出现；
- 截面是 T 形，没有轮辋筒体；
- 参数表里的 18″ / 8.5J / ET35 / PCD 114.3 / 9.2 kg 在照片里都看不到，全是模型编的。

这类输出**绝不能进入建模或报价流程**。

参考自身的一致性：照片 SAM 遮罩按固定 45° 旋转、组与组比较，IoU 只有 0.25–0.48（平均 0.35）。原因有斜拍、凹面视差、SAM 噪声，另外辐条很细，角度偏一点 IoU 就掉得厉害。所以 0.64 **分不出**「忠实还原」和「合理重画」，定量结论要等人工标注（`experiments/annotate`）。

## 结论

1. 正视图：两个模型都保留了组数（8 组 × 双辐 = 16 条）、双辐夹缝、中心盘五孔。肉眼看是可信的「去透视」重画。
2. 不能当几何真值：
   - 模型会改比例：qwen 的轮唇占比多约 8%；
   - 会改细节：辐条末端、窗口圆角都变了；
   - 目前的参考遮罩也分辨不出这些偏差。
3. 截面：生图模型不懂截面。wan 画成正视线稿；qwen 画出一张像样但几何错误、参数编造的「工程图」。轮辐厚度和凹面深度仍需参数化模板或人工补。
4. 可用的定位：给窗口法拟合提供正视初值或做人工参考。要以照片为准，生成图只当先验。
5. 选型：wan2.7-image 更快（约 9 秒对 60 秒），也更听「纯黑白剪影」的指令，适合做剪影。qwen-image-3.0 更写实，适合给人看。

## 边界

- 只测了一张照片、每个视图一次采样，没评估随机性。
- 旋转角只有模 45° 有意义。
