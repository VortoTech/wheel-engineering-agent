# 照片参考双辐样例

2026-09-13 · 模板 `forged-monoblock-v4` · 本地 v0.3 历史样例

当前 v0.4 的优化样例与识图入口见 [单图拟合与本地识图](photo-fitting.md)。本页保留上一版参数记录。

## 已实现

按用户提供的照片人工分析，建立 8 组 / 16 根细支臂的参数化单片近似模型。每组采用实体放样和 U 形贯通分叉，随后阵列、与中心盘及轮辋融合并倒圆。分叉进入真实 STEP，也作为独立加工特征导出。

“新建双辐样例”会创建独立项目。可调整组数、组内净间隙、单支臂外端宽度、分叉距中心盘外缘、整体相位，以及原有直径、宽度、ET、孔系和凹面参数。不可行组合在排队前拒绝；当前双辐不支持偏转和背腔。原有单辐模式保留。

| 输入 | 样例值 | 依据 |
| --- | --- | --- |
| 组数 / 支臂数 | 8 / 16 | 照片人工观察 |
| 轮辋规格 / ET | 22×8.5J / 35 mm | 为匹配比例采用的假设，非照片测量 |
| 孔系 | 5×114.3 / 中心孔 66 mm | 假设；照片仅支持观察孔数 |
| 组内间隙 / 端宽 / 分叉起点 | 34 / 6 / 8 mm | 人工拟合，非工程尺寸 |
| 气门孔 | 11.3 mm、270° | 示意通孔，未设计实际气门嘴座 |
| 周圈紧固件 | 40 个展示件 | 数量、尺寸、连接位置均为假设 |

## 外观与工程文件

`wheel.step` 是单一成品实体。`wheel.glb` 将同一个实体分为银色轮辋和黑色轮心区域；导出时核对分区体积之和等于成品体积。

`presentation.glb` 另加中心盖、装饰圈和周圈螺栓，可在界面关闭。这些附件不进入成品 STEP、体积、重量、卡钳或锻坯检查，也不进入加工特征。ZIP 内包含两种 GLB，报告明确附件范围。

本样例输出 33 个语义加工特征和 8 组候选工序；包括 8 个双辐放样组和 8 个 U 形分叉。工序仍为交接草案，未生成刀路。

## 图片依据与差异

原图 SHA-256：`8053104275f9ad59c005590cd1f7925bd4109e4980248ec8ca3419631ba75bf6`。照片作为项目参考原件保存，源码库不包含照片。

照片带有透视，背面、截面、真实厚度和装配方式未知。样例保留双辐数量、细长分叉、黑银分色和外围螺栓的视觉特征；轮唇宽度、辐根细节、中心盖和凹面尚未精确还原。照片上的外观可能来自分体结构，本样例并未设计分体连接、密封和紧固。

`scripts/create_photo_study.py` 可生成本地照片标注与 CAD 正面投影对照页。标注是人工像素观察；椭圆仅辅助比较构图，不表示相机标定或毫米尺度恢复。

下一步先依据正面与背面资料细化轮唇、辐根和中心盘，再用实际直径、宽度、ET、PCD、中心孔及截面尺寸校准。实际卡钳、锻坯和材料数据补齐后，可复用现有检查。强度、疲劳、轮胎配合及实际加工仍未验证。
