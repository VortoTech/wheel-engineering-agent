# WheelCAM 产品与技术框架 v0.2

日期：2026-09-12。方向：锻造定制单片轮毂。

## 1. 产品目标

将客户图片、工程尺寸与已确认的约束转为可编辑轮毂 CAD，再交给工厂完成 CAM、后处理与加工验证。主攻改装及定制市场的单片锻造轮毂，铸造毛坯后加工保留为未来扩展。

第一阶段的价值是减少重复建模和加工资料整理。当前为本地数字样机；参考图片由人判断，所有初始尺寸均标注为模板假设。

## 2. 当前工作流

```text
参考图片 + 人工尺寸 → 参数化成品 CAD → STEP / GLB / 版本配方
                              ↓
           卡钳整圈包络 → 避让检查
           回转锻坯规格 → 包含关系、缺料与最小余量
           材料与密度 → 成品、锻坯、去除材料重量
                              ↓
           模板加工特征 → 候选工序 → 版本绑定交接包
                              ↓
           工厂确认选面、装夹、刀具、CAM、后处理及试切
```

## 4. 几何与坐标

Python / CadQuery / Open CASCADE 生成 B-Rep 实体。轮毂轴为 Z，轮辋宽度中面为 Z=0，+Z 指外侧，安装面 Z=ET。尺寸均为毫米，轮辋规格输入明确使用英寸。

轮辋截面旋转产生轮辋。轮辐有两种构造：放样（v9：轮辐截面放样及阵列、背腔布尔切削）和窗口法（v10：中心盘与轮辐坯同轴回转并先合并，再按窗口轮廓竖直铣穿，窗口棱边倒圆）。最后切出安装孔和气门孔。

窗口法的窗口轮廓来自照片标注拟合（`services/wheelcam/window_fit.py`）。流程如下：

- **相机**：先让外圈投影贴合标注椭圆。候选相机里，选各组在假设正面上重复得最一致的一个；一致性取留一法，每组对照其余各组。
- **窗口**：拟合组叠加平均后，每个开口区域生成一条轮廓。
- **评分**：用留出组打分。

轮廓只描述正面平面形状。侧壁竖直、无拔模；前后曲面、厚度和凹面深度仍是模板假设。模板会逐项校验：每个窗口位于中心盘与轮辋之间，不超出一组的角度，与其他窗口（含相邻组的副本）之间至少保留 4 mm 辐条。气门孔定位于深槽底部中间，周向角以 +X 为 0°，绕 +Z 为正；倾角 0° 表示径向，正角朝 +Z。孔径 0 表示关闭；启用范围 5–16 mm。孔型与具体气门嘴密封座尚未匹配。

当前轮辋是近似截面，不能据此认定符合轮胎配合规格。CAD 拓扑、孔贯通与体积检查和真实设计验证分开记录。

## 5. 工程输入与计算

### 卡钳

轴向范围以安装面为基准，转换为模型 Z 坐标时加 ET。输入径向/轴向矩形旋转 360° 形成环形实体，覆盖全部相对转角。先算与成品实体的交叠体积，再计算最小距离；接触单列为间隙不足。要求间隙由用户输入。

这种包络是保守近似，可能高估真实卡钳占据的空间。结论仅对输入包络有效；未覆盖配重、气门嘴、装配误差或受载变形。没有输入时为未检查。

### 锻坯

当前规格支持圆柱或杯形回转体，内腔向 -Z 开口，外侧底厚从 +Z 端测量，中心 Z 相对轮辋中面。内腔直径为 0 或底厚等于总高时为实心圆柱。

缺料体积取 `成品 - 锻坯` 的实体体积，避免只比较外廓。完整包含后，计算成品到锻坯所有边界面的最小距离作为统一余量；此版本不区分保留表面和待加工面。

只有完整包含时计算 `去除体积 = 锻坯体积 - 成品体积`、`去除率 = 去除体积 / 锻坯体积`。缺料时两项为空。余量不足仍可以给出几何去除量，但状态明确显示不足，不表示可加工。

布尔结果须有效。体积判定容差 0.001 mm³，距离数值容差 0.00001 mm；这些是软件数值容差，不是制造公差。

### 重量

`重量 kg = 体积 mm³ × 密度 kg/m³ / 10⁹`。材料缺失时不估算。锻坯与成品按同一种均匀密度计算，不含附件、涂层、材料缺陷和密度偏差。UI 启用的 2700 kg/m³ 是可替换的演示假设，不代表已确认材料牌号。

体积本身不能转换为可信加工工时；报价需要工厂的刀具、策略、切削参数和实际节拍数据。

## 6. 特征与交接

从模板输出轮辋回转轮廓、安装面、中心孔、各安装孔及锥面座/沉孔、各轮辐曲面、窗口、背腔和可选气门孔。每项包含语义标识、尺寸/截面、位置/方向和候选加工方式。

窗口用相邻轮辐及内外边界描述，不能当成固定角度扇形孔。特征不依赖易变化的 STEP 面编号；当前没有自动将语义标识绑定到 CAM 选面，交接后仍须确认几何区域。

工序按类型分组，编号不代表已验证顺序。候选装夹不包含已确定的机床坐标、夹具或刀具。没有工厂资料时仍可生成数字草案，但不会输出可执行 NC。

交接包包含成品 STEP、GLB、参数配方、检查报告、特征 JSON、工序 CSV，以及启用时的锻坯与卡钳包络 STEP。模型 ID、草稿版本、模板版本、来源和 STEP SHA-256 建立关联。

## 7. 保存、任务与失效

React / Three.js 前端，FastAPI 服务，SQLite 元数据及文件保存。每次修改采用草稿版本号进行并发检查；模型生成排队后在独立 Python 子进程中执行，失败不覆盖历史版本。

卡钳、锻坯、材料各自保存来源与备注，跟随任务快照冻结。重新加载历史参数时同时恢复对应工程输入；任何输入修改均提示当前显示的是历史模型。历史版本没有某项报告时显示未检查。

v2 草稿升级到 v3 保留有效参数组合与来源，新气门孔默认关闭。历史任务不迁移。运行数据、构建产物、依赖和日志不纳入 Git。

## 8. 后续接入与验收

先拿到真实轮毂、卡钳及锻坯资料核对数字样例。能写成"一种窗口形状 × N 组"的造型（Y 形分叉、双辐、多辐），都由窗口法覆盖。图片识别（外圈与窗口标注 → 窗口轮廓）只作为待确认的候选输入，放在模板覆盖和交接验证之后。

CAM 采用成熟软件适配；工厂确定软件、机床、刀具、夹具及后处理后，验证一台机床的一道工序，再扩展完整流程。需要分别记录软件验证、独立 CAD 验收、加工仿真、现场试切和轮毂产品验证的证据。
