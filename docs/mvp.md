# 锻造定制实施路线

日期：2026-09-12。代码现状以 [本地工作台](local-workbench.md) 和 [验证记录](validation.md) 为准。

## 首版目标

在一个单片锻造模板上打通「人工参考图片与尺寸 → 参数化 CAD → 卡钳/锻坯检查 → 加工交接草案」。利用已知模板输出带尺寸和位置的加工特征，减少重复建模与交接整理。

没有工厂资料也可以验证软件算法和文件协议；真实适配结论、报价、加工与产品验证须接入实际资料。

## 阶段

| 阶段 | 当前进度与交付 | 验收 |
| --- | --- | --- |
| 基础样机 | v2 参数化模板、项目保存、图片、来源、版本、STEP / GLB | 实体样例、孔系探针、STEP 回读、任务失败与恢复 |
| P1 造型与适配 | v3 增加气门孔、整圈卡钳包络检查；后续扩充 Y 形分叉辐等 | 气门孔真实贯通；卡钳干涉、接触、间隙不足/满足可区分；用真实造型验证模板 |
| P2 锻坯与估算 | 圆柱/杯形锻坯、缺料与最小余量、去除率和重量 | 包含、局部/全部缺料、偏移、余量不足样例；重量单位正确；随后用实际锻坯校准 |
| P3 CAM 交接 | 已提前做模板特征 JSON、工序 CSV、版本绑定交接 ZIP | 交接文件与模型摘要一致；工厂确认选面和装夹；随后接一个 CAM、一道工序并验证试切 |
| P4 图片辅助 | 尚未实现 | 候选轮辐数、造型和比例可追溯、人工确认；真实样例中减少出初版模型的时间 |
| P5 客户端 | 尚未实现 | 按实际业务需要增加在线配置和效果预览 |

P1–P3 的基础软件能力可以交错实现，不把文件草案导出视为 CAM 接入完成。

## 本轮交付范围

1. 保留并提交此前 v2 基线，建立独立的 v3 变更记录。
2. 气门孔直径、周向位置及倾角，孔径 0 为关闭；实际实体切削和贯通检查。
3. 可选卡钳整圈保守包络，输入以安装面定位；无输入为未检查。
4. 可选圆柱/杯形锻坯，检查成品完整包含、缺料体积、最小余量；缺料时不输出去除率。
5. 可选材料与密度，输出 CAD 净重及锻坯/去除材料重量。
6. 可定位的模板特征、候选工序、JSON / CSV / ZIP 导出；保留版本和来源。
7. 分开展示 CAD、卡钳、锻坯及重量状态；草稿变更不覆盖历史检查。

## 本轮验收用例

- 原有四组模板样例仍为单一有效实体，原有导出与 API 行为继续通过。
- 正/负气门孔倾角都贯通，并保留孔周边材料。
- 只在某一周向位置出现的轮辐/几何仍被整圈卡钳检查覆盖，ET 变更影响轴向对齐。
- 外径和总高足够但内腔缺料的锻坯不能判定通过；偏移与余量不足可检测。
- 无资料不计算；非有限值、非法尺寸和密度在任务前拒绝。
- 文件内模型 ID、草稿版本、STEP 哈希及配方一致；旧输入不随草稿更新。
- 实际本地工作台完成录入、生成、查看报告和交接导出；独立 CAD 和真实工厂验证另记。

## 下一步需要的资料

| 资料 | 用途 |
| --- | --- |
| 1–3 款真实轮毂的规格、照片与造型尺寸 | 验证现有模板与选择下一类模板 |
| 卡钳相对安装面的尺寸/轮廓、要求间隙及来源 | 校准包络适配结果 |
| 锻坯截面/STEP、定位基准、余量与材料密度 | 校准包含关系、去除率和重量 |
| 合作厂 CAM、设备、刀具、夹具和已验证后处理 | 从交接草案推进到真实加工 |
| 公差、标准轮辋截面、载荷和验收要求 | 独立工程设计和产品验证 |

工时和报价待工厂实际数据；不会由去除率直接推定。结构安全、轮胎配合及加工发布不以当前 CAD 检查通过作为验收。
