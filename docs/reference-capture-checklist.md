# 轮毂复刻资料收集清单

日期：2026-09-13。用途：可直接发给商家、实物持有人或合作工厂。

这里的“复刻”需先约定目标：外观接近、实物尺寸一致、可制造并适配指定车辆，三者所需资料不同。单张照片只能支持可见造型拟合；照片再多也不能直接确定全部隐藏结构、公差、材料和性能。精确复刻应约定各项允许偏差，以原厂 CAD / 图纸或实物测量为基准。

## 1. 先确认对象和目标

- [ ] 品牌、完整型号、商品链接或零件编号。
- [ ] 照片对应的具体规格、前轮 / 后轮版本；同款不同尺寸、ET 可能采用不同轮心曲面。
- [ ] 单片 / 两片 / 三片结构；周圈螺栓是真实连接还是装饰，无法确认的填写“未知”。
- [ ] 目标：复原原款规格，还是保留造型并适配另一组规格 / 车型。
- [ ] 哪些细节必须一致：轮唇、辐根、凹面、中心盖、孔周凹槽、外围螺栓、表面处理。
- [ ] 是否有原厂 STEP、原生 CAD、二维图纸、截面图或检验报告；记录文件版本与对应实物。

## 2. 照片清单

建议先提供下列 6 类照片，加 4 类细节特写。数量仅为采集建议，重点是覆盖结构与清晰程度，不以固定张数保证精度。

| 勾选 | 照片 | 拍摄要求 | 主要用途 |
| --- | --- | --- | --- |
| [ ] | 正面正对轴线 | 镜头与中心盖等高，整轮完整入镜，尽量正对；保留未经裁切的原图 | 双辐轮廓、孔位、轮唇和中心盘比例 |
| [ ] | 背面正对轴线 | 尽量取下遮住结构的包装；安装面、轮辐背部、轮辋内侧完整可见 | 背腔、安装面、结构连接 |
| [ ] | 左前约 45° | 中心盘到外缘均清楚 | 凹面、分叉和轮唇层次 |
| [ ] | 右前约 45° | 拍另一侧，避免高光持续遮挡同一部位 | 补足另一侧轮廓 |
| [ ] | 侧面平视 | 从侧面拍清内外轮缘、轮心位置；必要时增加侧后视角 | 轴向深度和位置关系 |
| [ ] | 背面规格刻印 / 标签 | 清晰近照，保留全部字符及所在部位 | 直径、宽度、ET、型号等来源 |
| [ ] | 一整组双辐正面特写 | 包含根部、分叉、中段和末端 | 外侧曲线、内窗口、圆角与端部连接 |
| [ ] | 同一组双辐背面特写 | 对应上述位置，并拍清侧壁 | 厚度变化、背腔、侧铣槽 |
| [ ] | 中心区域特写 | 中心盖、安装孔沉孔与孔座；如有可安全取下的中心盖，可另拍盖下结构 | 中心盖与孔系细节 |
| [ ] | 轮唇及周圈连接特写 | 从正面和侧后方拍；另补气门孔细节 | 轮唇截面、连接层次、螺栓与气门孔 |

通用拍摄要求：

- 使用同一只轮毂，或明确标记每张照片对应哪只及其规格。不要把不同 ET、不同尺寸的同款照片混用。
- 发原始照片文件；避免聊天软件压缩图、截图、滤镜、景深虚化和自动美化。
- 尽量采用均匀柔光；黑色轮辐要能看清边缘，银色轮唇不要大面积过曝。
- 避免超广角近距离拍摄。能后退时适当后退，保持整轮清楚；有光学长焦可使用，但不依赖数码放大补细节。
- 测量特写将尺子与被测轮廓放在尽量相同的平面；不能把前方尺子的比例直接套给后方曲面。
- 如有实物，裸轮毂通常更方便观察；轮胎遮挡的胎圈座和截面需另用图纸或测量补足。不要为拍照自行拆解承力连接或密封结构。
- 可补一段缓慢环绕视频帮助理解连接关系；视频不代替原始照片、尺寸和截面资料。

### C. 精确几何与制造：进入工程阶段补齐

- [ ] 轮辋完整径向截面：轮缘、胎圈座、凸峰、深槽、内外壁；优先原厂截面图 / CAD。
- [ ] 安装面位置、厚度、平面范围，中心孔台阶、倒角和定位结构。
- [ ] 安装孔通孔、沉孔、孔座形状、配套紧固件；锥面角或球面半径需明确。
- [ ] 轮辐背部截面、背腔深度、底厚、侧壁、隐藏过渡和加工槽。
- [ ] 若为分体：各独立零件、搭接面、连接孔、紧固件规格、密封结构与装配图；不能把装饰件模型当作连接设计。
- [ ] 材料牌号、热处理状态、毛坯类型与实际锻坯几何。
- [ ] 尺寸公差、形位公差、粗糙度、表面处理与相关厚度要求。
- [ ] 载荷目标、预期用途、适用验证要求和已有检测资料。

若追求实物几何的高精度一致，应优先争取原厂 CAD / 图纸；没有时，可采用实物三维扫描结合关键尺寸测量。扫描网格仍需检查单位、精度、遮挡和基准，再转换为工程模型；扫描外表面不能自动恢复不可见内腔、材料和公差。

## 4. 目标车辆适配资料

这些资料用于“装得上且不干涉”，不直接决定正面造型。

- [ ] 车型、年份、前 / 后轴、目标轮胎规格和悬架 / 制动改装。
- [ ] 轮毂安装面基准、轴头定位直径与突出高度、紧固件和孔座要求。
- [ ] 制动盘和卡钳的确切型号、三维包络及其相对安装面的坐标；同时记录所需间隙依据。
- [ ] 内侧悬架 / 转向部件及外侧轮眉空间；不同运动状态的间隙由适配方核验。

Forgeline 的适配表分别收集前后轴空间、卡钳与轴头尺寸，说明仅有 PCD 和 ET 不足以确定完整适配。[Forgeline 官方适配表](https://www.forgeline.com/cdn/shop/t/4/assets/FitmentV4.pdf?v=151876044356234396341773183342)

厂家提供的纸质卡钳模板可辅助初步检查，但定制设计宜获取该制动系统的三维数据。例如 Wilwood 在其 DS-1677 的第 2 页明确区分一般适配示意与定制车轮设计，并要求定制厂家取得制动套件的三维模型。不要把此套件的间隙数值推广为所有轮毂的统一要求。[Wilwood 官方说明](https://www.wilwood.com/PDF/DataSheets/ds1677.pdf)

## 5. 表面外观

- [ ] 颜色名称 / 色号或实物色样；不同光线下的照片仅作辅助。
- [ ] 喷粉、喷漆、阳极、抛光、拉丝或车亮面等处理方式。
- [ ] 哑光 / 半哑 / 亮光程度、拉丝方向及各区域分色边界。
- [ ] 中心盖、标志与雕刻的位置、尺寸及已有图案文件。
