## 录制前的核对

1. 只用授权、脱敏后的订单图和匿名统计；不展示原始客户 CAD、凭据、SSH 地址、用户目录和环境文件。
2. 主线每一帧从同一 Spark 运行目录取证；记录 Git 提交、输入摘要、模型名、每步时间、失败项和 `manufacturing_status`。
3. 演示词按实测改：无 PDF 就打开 SVG；造型 Agent 未调用就显示未调用；完整造型 STEP 没通过就展示加工级 STEP 的边界。
4. 参考 NC 是注释轨迹，不可上机；采样去料不是机床、夹具或刀柄碰撞仿真；L0–L3 都不代表制造批准。
5. 留一份本机录屏备份。路演时可在真实运行与预录视频之间切换，但必须明示何时播放预录结果。
6. 对话修改只更新当前网格预览；展示工作台的版本提示，不能把旧 STEP、工程图、加工包说成修改后的输出。
