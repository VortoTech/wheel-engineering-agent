# 单张照片的造型拟合与本地识图

2026-09-13 · v0.4 · `forged-monoblock-v5`

当前可用的是传统图像几何候选检测，不是通用视觉大模型，也不是图片直接恢复完整工程 CAD。先识别外圈、周期双辐和局部边缘，人工核对后将受支持的候选参数应用到草稿，再由参数模板生成 CAD。

## 操作

1. 使用“新建双辐样例”，或选择已有双辐项目。上传原图并设为主参考。
2. 打开“照片对照与识图”，点击“自动识图 · 提取候选”。识图前保存草稿，检测本身不会修改参数。
3. 如果确实知道参考实物的最外缘直径，可输入毫米数；不知道就留空。不能用标称 22 英寸代替照片最外缘直径。
4. 查看外圈、局部点位和候选组数 / 相位；只有满足图像证据与当前模板约束的参数可以应用。参数改变或主参考图切换后，旧候选需要重新计算。
5. 确认候选后应用到草稿，再生成新版本。金色投影来自该版本真实 CAD 的正面可见边线，不是理想化草图；识图点位和 CAD 投影可以分别观察。
6. 可微调投影透明度、平移、缩放和旋转。微调仅影响当前视图，不是尺寸校准，不写入工程参数。

应用记录包含图像 SHA-256、算法版本、检测分辨率、基准草稿、候选参数和可选标尺。生成后的配方保存该记录；原始图片不被修改，已生成历史文件不覆盖。

## 比例和尺寸

检测在最长边不超过 720 px 的灰度图上进行，输出外圈椭圆和无量纲局部比例。给定参考实物外径后，可计算相应参考长度估计；应用到目标 CAD 时，按目标模型外径映射候选比例。参考实物和目标模型的规格分开。

当前照片没有实测标尺。现有 22×8.5J、ET35、PCD 和中心孔等继续是演示假设。不能从图片推断材料、ET、背面厚度、孔座、连接方式或制造公差。

外圈椭圆只提供仿射对齐，不能消除所有透视和不同曲面深度的影响。边缘残差单位为检测图像素，不是实物毫米精度；边缘覆盖率不是“识图正确概率”。

## 本地检测的范围

`radial-edge-pairs-v1` 使用梯度中心投票、径向边缘峰、稳健椭圆拟合、外围暗色双辐周期匹配和局部亮度剖面。当前假设轮毂完整、接近正面、位于画面中部、占据较大区域，且外围有可区分的深色双辐。

低对比度、裁切或找不到连续外圈时拒绝识别。周期结果有歧义时只显示候选，禁止套用。单辐项目不能直接用双辐检测覆盖结构类型。不会悄悄将不满足尺寸范围的结果截断到边界值。

对当前工厂照片，自动候选为 **8 组、5.5° 相位**。外端宽度尚未通过范围筛选，中段点位会受背景污染，因此该照片当前只允许套用组数和相位；轮唇宽度、辐根展开等来自明确标注的人工照片拟合。完整轮廓跟踪和点位编辑仍待后续实现。

## 本次可见造型优化

- 新增加宽轮唇的旋转截面，径向向内延伸和轴向落差可独立设置，实际进入成品 STEP、体积和加工特征。
- 双辐增加 1/4 段展开量和中段宽度增量，通过同一组放样截面生成实体；末端可在宽轮唇上内收。
- 周圈展示螺栓随轮唇内移，增加装饰圈层次；中心展示件增加孔位轮廓、较小的中央装饰圈和银色孔周衬环。
- 展示附件仍不进入 STEP、重量和工程检查。轮唇背面截面、厚度与分体装配仍未由照片确认。
- 旧草稿的新字段采用 0 增量，保持原单辐 / 双辐轮廓；历史模型保持原文件。

连接圆角可能因宽轮唇交线而降级。本次优化样例中心盘侧为 3 mm，轮辋侧为 0.9 mm，报告保留实际值；尚不能当作最终加工几何。

## 后续优先项

先提升前景分割、局部边缘追踪与人工修正能力，让内窗口和外轮廓有可靠点位，再将更多比例纳入约束拟合。可另接通用视觉模型提出语义候选，但仍需要像素点位核对与 CAD 约束检查。新增资料收集方式见 [复刻资料清单](reference-capture-checklist.md)。
