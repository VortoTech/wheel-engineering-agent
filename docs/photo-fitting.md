# 单张照片的造型拟合与本地识图

2026-09-13 · v0.5 · `forged-monoblock-v6`

当前为本地像素边缘检测与参数化拟合，尚未接入通用视觉大模型。v0.4 对这张工厂照片只应用了组数与角度，中段点位没有进入 CAD，这是辐条差距较大的原因之一。v0.5 增加连续辐边跟踪，并将根部展开、中段宽度、外端净间隙、支臂端宽及分叉间隙渐变实际用于建模。

## 操作

1. 选择双辐项目，上传原图并设为主参考。已有图片可以直接重新识图。
2. 打开“照片对照与识图”，点击“自动识图 · 提取候选”。检测不会直接修改草稿。
3. 有实测最外缘直径才填写参考毫米数；未知可留空，不能用标称英寸代替最外缘直径。
4. 青色为外圈，粉色为逐条边缘候选，弱对比区留空。关闭 CAD 投影可单独核对识图；“对照放大”可查看辐根细节。
5. 查看各截面的支持组数、拟合前后宽度偏差及候选参数。证据不足或不满足几何约束时，不修改相应轮廓。
6. 核对后应用到草稿，再生成新版本。金色边线始终来自已生成版本的实际 CAD 正面投影。

图像、算法版本、基准草稿、比例、候选和检测记录随配方保存。修改参数或主参考图后须重新检测。对照视图的平移、缩放、旋转仅影响显示，不修改尺寸。

## 检测与拟合范围

`continuous-blade-sections-v2`：

- 最长边 720 px 的梯度投票、径向边缘与椭圆拟合，确定外圈和双辐周期。
- 在最长边 1440 px 的图像上沿每根支臂连续跟踪两侧边缘；保持中心与宽度连续，限制跨到相邻组或外端大块背景。
- 当前追踪范围为外圈半径的 0.36–0.86，最内侧分叉圆弧和最末端收口仍是模板假设。所有返回点位统一映射到 720 px 检测坐标系。
- 根部、中段、外端分别汇集多个径向截面，每组只投一票；至少一半组数且不少于三组支持、组间离散不过大才参与拟合。
- 新增 `paired_gap_flare_mm`，让分叉处净间隙向中段平滑收敛到外端间隙。Bezier 槽实际切入 STEP；加工特征同时记录根部间隙、渐变起止位置。
- 根部展开、中段展开的参数范围放宽，但相邻窗口、背面最小宽度等组合约束继续检查。候选超限时向原草稿收缩并披露采用比例；仍不合法则不应用。

“截面宽度偏差 RMS”只比较三个截面的净间隙和整组宽度，不是整圈相似度、完整 CAD 边线误差、识图正确概率或制造精度。拟合使用了这些观测，偏差下降不能代替独立实物核验。车间背景、黑色附件、高光和遮挡仍可能导致错误候选。

## 比例与工程尺寸

图片目前没有实测标尺。22×8.5J、ET35、PCD、中心孔、背面厚度等仍为原有演示假设。拟合只将图像比例映射到当前目标模型外径；不会据此推断材料、ET、PCD、背面或制造公差。

外圈椭圆只作仿射对齐，不能恢复不同曲面的透视和深度。装饰盖、周圈螺栓等仍仅展示，不进入 STEP、重量和工程检查。渐变槽尚未经过结构分析或加工验证。

旧草稿新增字段默认 0，维持原来的等宽槽；原有尺寸来源和历史模型文件不变。新版候选须重新分析、应用、生成。

## 后续优先项

继续提升背景排除与分叉圆弧识别，补充可拖动的人工修正点，以及能把修正点重新拟合到轮廓的闭环。再做独立标注的边线误差评估和相机姿态拟合。当前已有连续边缘候选，尚未实现任意照片的自动完整复刻。资料要求见 [复刻资料清单](reference-capture-checklist.md)。
