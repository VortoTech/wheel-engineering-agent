# 单张照片的造型拟合与本地识图

2026-09-13 · v0.7 · `forged-monoblock-v8`

当前为本地像素边缘检测与参数化拟合，尚未接入通用视觉大模型。v0.6 在连续辐边与截面拟合基础上，增加相机姿态拟合、独立分叉底角和可修改的三个分叉点。修改会进入真实 CAD；对照界面使用生成模型的实际三维投影。

## 操作

1. 选择双辐项目，上传原图并设为主参考。已有图片可以直接重新识图。
2. 打开“照片对照与识图”，点击“自动识图 · 提取候选”。检测不会直接修改草稿。
3. 有实测最外缘直径才填写参考毫米数；未知可留空，不能用标称英寸代替最外缘直径。
4. 青色为外圈，粉色为边缘候选。应用候选、生成新版本后，金色实际模型按拟合视角叠回原图。可调透明度；关闭相机拟合对照可查看原有 CAD 正面线稿。
5. 需要修正最内侧分叉时，打开“显示可拖动分叉点”，选择清晰的一组。调整底部中点及两侧圆弧接续点，也可直接输入像素坐标。“回到图片调整”可定位到放大的对照图。
6. 点击“按点位重新拟合”，核对候选，再确认应用到草稿、生成新版本。只有重新生成后，金色模型才代表修改后的 CAD。

修改点位会创建新的分析记录，不覆盖旧分析或自动修改草稿。配方保留主参考图摘要、分析版本、相机假设、修正点和参数来源。草稿过期、跨项目分析、左右点顺序错误或不满足几何约束时会拒绝应用；手动改点后不再显示旧截面评分为当前结果。

## 检测与拟合范围

算法 `camera-root-contours-v3`：

- 最长边 720 px 的梯度投票、径向边缘与椭圆拟合确定外圈和双辐周期；在最长边 1440 px 的图像上连续跟踪支臂边缘，返回点统一使用 720 px 检测坐标。
- 连续追踪主要覆盖半径的 0.36–0.86；根部、中段、外端汇集多个截面，至少半数组且不少于三组支持才参与宽度拟合。弱对比、遮挡和车间背景仍会干扰结果。
- 分叉底部使用独立的圆角槽端：`paired_root_round_mm` 控制两侧底角，`paired_split_start_mm` 控制起点，`paired_gap_flare_mm` 控制根部间隙向中段的收敛。它们实际切入 STEP，不是只改变显示线条。
- 自动底角拟合比较多个对称组的局部边界对比度；手动三点则按拟合相机反投影到当前假设的辐条前表面，再求起点、底角和根部净间隙。所有组共享参数，不会单独扭曲某一根辐条。

## 大窗口与整圈骨架试验

v0.7 增加相邻双辐之间的大窗口底部曲线。它与双辐内部的小 U 形开口共同决定根部材料宽度，直接进入实体、STEP、特征配方和照片投影。

- **大窗口底部外移** `paired_window_root_mm`：相对中心盘半径向外的距离；0 关闭并保留旧模板形状。
- **大窗口过渡终点距中心盘** `paired_window_blend_mm`：沿辐条径向的过渡终点位置，不是从窗口底部计算的圆角半径。终点必须比底部至少外移 15 mm。
- 两侧三次曲线关于窗口中心线对称，映射到各辐条截面。根部用加密截面和受限三次曲面，外侧细辐单独放样，避免根部控制扰动细长末端。八组仍按旋转对称生成。
- 开启后保留已确认的整组宽度；原五截面自动宽度反解不再适用，因此不自动覆盖这些宽度。相机拟合、小 U 形分叉点位修正继续可用。大窗口参数当前为人工试拟合，尚未自动提取大窗口点位。
- “当前 CAD 的骨架粗细”表列出辐根过渡、前段、中段、后段、末端的单臂正面宽度和前后厚度。数值来自该生成版本的截面控制，不代表扣除圆角后的最小实体壁厚，更不是照片测量结果。

本次试验使用底部外移 20 mm、过渡终点距中心盘 55 mm。这是模型尺度下的外观试验，不能当作实物尺寸。旧项目两个新参数默认 0 / 55，外移为 0 时几何路径保持原样。

新骨架的平面圆弧不等于三维连接倒圆：旧批量倒圆不能用于新增的辐条交汇边，因此此模式下三维连接倒圆不执行，报告记录实际 0 mm。曲线也不是恒定半径圆弧，空间连续性、局部最小壁厚、强度和加工性还需后续验证。

## 透视处理与评价

相机拟合同时使用外圈和多组辐条轴线，优化倾斜、旋转、中心与尺度。偶数组用于拟合，奇数组留出检验；预设有限距离和近似正交的相机候选，按拟合组误差选择，只有拟合组和留出组均改善且外圈残差合格才采用，否则保留基准视角。

这是固定当前 CAD 深度后的相机拟合，不是单图恢复真实相机标定或轮毂深度。界面将实际 GLB 按该相机投影到原图，正面 CAD 仍保持旋转对称。不会为了贴合照片而把工程实体整体拉成椭圆。

“留出组轴线偏差”只衡量未参与求解的检测轴线对齐；“截面宽度偏差 RMS”比较拟合所用的三个截面宽度。两者均不是完整轮廓误差、识图正确概率、实物复刻准确率或制造精度。照片候选也不是独立人工标注的真值。

## 比例、兼容与当前边界

图片没有实测标尺。22×8.5J、ET35、PCD、中心孔、背面厚度等仍为演示假设。拟合将图像比例映射到当前目标外径，不会据此获得真实毫米尺寸、材料、背面或公差。中心盖和周圈螺栓仅用于展示，不进入 STEP、重量和工程检查。

旧草稿新增底角字段默认 0，继续使用原半圆槽端；保留已有参数和来源，历史模型文件不重建。新版候选须重新分析、应用、生成。

当前照片自动样例的分叉起点为 0 mm、底角为 12 mm，均是目标模型尺度下的候选。实体及 STEP 回读有效，但中心盘和轮辋连接圆角均由请求的 3 mm 降级为 0 mm，报告已记录；独立分叉底角与连接圆角是不同特征。中心区域、外侧窗口、轮唇及立体曲面仍有差异，完整外观、结构和加工验证尚未完成。

下一步应先对清晰组的分叉和窗口边界人工标注，评价完整投影边线误差，再增加模板表达能力。只有补充真实尺寸与更多视角，才能进一步约束深度与工程几何。资料要求见 [复刻资料清单](reference-capture-checklist.md)。
