## 修复内容

- 图片上传增加可选的视觉造型修正，后端显式校验视觉模型配置；开启时同时做照片叠图和评分。默认关闭，无模型仍可建基础草案。
- 对照页新增照片叠图、边缘距离及窗口 IoU，首次照片 Agent 的改动进入参数前后表。对话修改后旧评分明确过期；评分不覆盖全部外圈盲窗，也不表示尺寸精度。
- 单个工作台进程内，不同版本的修改/构建共享互斥门，冲突返回 409；保留同版本锁。当前 CLI 单进程部署有效，不是跨多 worker/多实例调度器。
- 当前前端提交配方 hash，旧版本对话在调用模型前返回 409。旧 API 客户端未带 hash 仍兼容。
- 生成任务 stdout/stderr 和超时输出保存在运行根目录 `.logs`，错误返回任务编号；失败仍保留父版本。
- 启动脚本同时配置对话和视觉模型；localhost 模型流量从全局代理中排除。未重启 Spark 模型服务。
