# Inputs, artifacts and acceptance

## Engineering parameters

| Field | Unit / meaning |
| --- | --- |
| diameter_in | Nominal bead-seat diameter, inch; not lip outside diameter |
| width_in | Nominal width, inch; not overall width |
| pcd_mm | Bolt pitch-circle diameter, mm |
| bolts | Bolt count, integer |
| center_bore_mm | Center bore, mm |
| et_mm | Offset, mm; preserve sign |

Keep supplied values distinct from inferred, default and unknown values. Photo mode accepts `--hole-form 15X32X60` for a drawing-confirmed hole recipe; do not attribute it to drawing evidence without a drawing or confirmed specification.

## Two STEP routes

Photo `--kernel brep` requests full styled geometry, which can fail or skip operations. Chain delivery uses a simplified machining model, excluding some styling surfaces. Success of the second route does not prove the first was built.

A case directory for chain mode contains `front.jpg` and `spec.json`; spec.json has a `spec` object containing the engineering fields. Optional views, hole form, provenance and visual-agent settings depend on the runtime's CLI contract. For revisions, use a snapshot generated by the runtime rather than inventing its internal schema. Inspect `scripts/demo_chain.py` in the configured runtime for the accepted snapshot fields.

## Evidence review

- `recipe.json`: regenerable parameters; not native CAD feature history.
- `engineering_report.json`: parameters, source, unknowns, questions, checks and readiness.
- `cad/report.json`: actual geometry, preparation status and skipped operations when present.
- `machining_report.json`: simplified geometry checks and adjustments requiring review.
- `chain.json`: per-step status and timing; a successful earlier step does not certify later ones.
- `delivery_manifest.json`: binds the version to delivered artifacts.

GLB is L0. Valid single-solid B-Rep with successful STEP round-trip is required for L1. L2 also needs confirmed user/drawing/measurement provenance for six key specs and passing checks. Catalog or unspecified inputs cannot upgrade readiness. Check whether ET is derived from construction rather than independently measured from STEP. Skipped style stages or failed preparation prevent claiming complete L3. Current L3 geometry checks are not structural or manufacturing certification.

Reference NC, SVG/PDF drawings and sampled material removal remain preparation drafts. No sampled gouge does not cover tool holder, fixture or machine collisions. Report whether PDF was actually generated. Keep `not_released`.
